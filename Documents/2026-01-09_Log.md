### Technical Implementation Details

**Explosion Damage Logic**:
```gdscript
# Old (broken - didn't scale):
explosion_damage = 10.0  # Fixed value

# New (scales with weapon):
explosion_damage_percent = 0.75
explosion_dmg = damage * explosion_damage_percent  # 75% of main damage
```

**Radius Scaling Logic**:
```gdscript
# CursedSkullWeapon.gd
func level_up() -> void:
    super.level_up()
    current_explosion_radius = min(
        base_explosion_radius + (level - 1) * radius_growth_per_level,
        max_explosion_radius
    )
```

**Visual Ring Rendering**:
```gdscript
class ExplosionRing extends Node2D:
    func _draw() -> void:
        # Filled circle (AOE area)
        draw_circle(Vector2.ZERO, current_radius, fill_color)

        # Outer ring (main indicator)
        draw_arc(Vector2.ZERO, current_radius, 0, TAU, 64, ring_color, 8.0)

        # Inner ring (depth)
        draw_arc(Vector2.ZERO, current_radius * 0.7, 0, TAU, 48, inner_color, 4.0)
```
