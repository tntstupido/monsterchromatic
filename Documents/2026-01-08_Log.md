## Technical Notes

### Speech Bubble Bug Fix
**Problem**: Speech bubble was being destroyed after first click.
**Root Cause**: Every call to `display_text()` was creating a new tween that connected to `queue_free()`.
**Solution**:
1. Track current tween in `_current_tween` variable
2. Kill old tween before creating new one
3. Only connect `queue_free()` when `auto_hide = true`
4. Pass `auto_hide = false` from shopkeeper interactions

### Jagged Edges Implementation
**Problem**: Procedural polygon generation failed with triangulation errors.
**Solution**: Use pre-made texture assets with TextureRect instead of procedural generation.
**Trade-off**: Less flexible but more reliable and better performance.

### Mobile Layout Optimization
**Design Decision**: 2x2 grid layout works better for portrait mobile screens than 1x3 horizontal layout.
**Sizes**: All UI elements scaled up 40% for mobile visibility.
**Spacing**: Reduced vertical gaps to fit more content on smaller screens.
